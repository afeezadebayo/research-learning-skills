Free **Agent Skills** (`SKILL.md`) that help Claude, Claude Code, OpenAI Codex and other AI agents research carefully and learn well: plan the question, search and evaluate sources, check facts, run interviews and surveys, review literature, synthesise findings, use AI tools safely and build lasting knowledge.

Part of the [Productivity skills](https://github.com/afeezadebayo/productivity-skills) library.

## All skills

| Skill | What it does |
|---|---|
| [`research-planning`](research-planning) | Turns a vague request into a sharp question, sub-questions, methods and a plan |
| [`desk-research`](desk-research) | Finds and logs published evidence, starting from primary sources |
| [`source-evaluation`](source-evaluation) | Judges whether a source is credible, with a confidence label |
| [`fact-checking`](fact-checking) | Checks every claim, number and quote before it goes out |
| [`ai-assisted-research`](ai-assisted-research) | Uses AI research tools without trusting them blindly |
| [`literature-review`](literature-review) | Reviews what research says on a topic |
| [`expert-user-interviews`](expert-user-interviews) | Plans and runs interviews that reveal what people really think |
| [`survey-design`](survey-design) | Surveys with clear questions and honest analysis |
| [`research-synthesis`](research-synthesis) | Turns findings into insights and recommendations |
| [`learning-plans`](learning-plans) | Plans learning a new skill |
| [`active-reading-notes`](active-reading-notes) | Reads and takes notes you can use later |
| [`spaced-repetition`](spaced-repetition) | Remembers what you learn |
| [`explain-to-learn`](explain-to-learn) | Learns by explaining |

## Install

```bash
git clone https://github.com/afeezadebayo/research-learning-skills.git
# Claude Code
cp -r research-learning-skills/research-planning ~/.claude/skills/
# Codex and other agents
cp -r research-learning-skills/research-planning ~/.agents/skills/
```

In Claude.ai or Claude Desktop, zip a single skill folder and upload it under **Settings → Capabilities → Skills**.

Then ask your agent, for example: *"Plan the research for this decision"* or *"Fact-check this report before I send it."*

## Start here

1. Run `research-planning` before searching.
2. Search with `desk-research` and judge what you find with `source-evaluation`.
3. Check the final output with `fact-checking`.
